# Carrom AI Showdown v0.3.1 — прицеливание и оформление

11.10.2026. Основной проект: `C:\Work\YTChatGPTvsClaudeCarrom`.

## Изменения

- Перед ударом биток стоит на реальной выбранной позиции; прицельная линия
  показывает угол решения. Через 1–3 секунды начинается удар; по умолчанию 2.
  Нет дополнительного запроса модели, корректировки угла или запуска физики во время aim.
- В официальном GUI время прицеливания резервируется из срока хода. Headless
  пропускает визуальную подготовку; протокол отличается по доступному API-времени.
- Сглаженные фишки с градиентом, ободком, бликом и мягкой тенью; спрайты кешируются.
- Девять дизайнов доски ImageGen: шесть обычных, Halloween, Новый год, Рождество.
  Узоры находятся по краям; физика и правила одинаковы для всех оформлений.
- При новой доске/R случайный выбор не повторяет предыдущую тему. Сезонный режим
  по локальной дате; `--board-season all` разрешает весь набор, `--board-theme` фиксирует тему.
- Replay хранит тему и кадры aim: время теперь физика + подготовка. Старые файлы
  v0.3 читаются. API wait и межбордовые паузы всё ещё исключены.
- Сверка концепции и следующие этапы — `CONCEPT_REVIEW.md`, `PROJECT_PLAN.md`.

EXE GUI проверялся через SDL dummy с сохранением PNG, не через новую запись OBS.
Реальная запись OBS подтверждена предыдущим релизом v0.3; в этой доработке код
OBS не менялся. Проверка на чистой VM, настоящие API и полный YouTube-выпуск
по-прежнему не выполнялись. Технический лимит двух ходов завершает проверочный
борд без спортивного победителя; это smoke, не полный матч.

Первая попытка сборки выявила отсутствие PyInstaller в проектной .venv.
Установлены существующие `requirements-build.txt`; повторная сборка успешна.
Ранее опубликованные zip v0.3 и исходные версии сохранены. Предыдущая установленная
Windows-папка сохранена в `backups/dist-before-v0.3.1` перед обновлением.
`.env` сохранён, в Source/Windows ZIP и `_internal` не включается.
