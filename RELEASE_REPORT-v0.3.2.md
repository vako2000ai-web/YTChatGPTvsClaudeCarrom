## Границы

Настоящие OpenAI/Anthropic и платные ElevenLabs не вызывались. Для TTS нужны ключ,
два разрешённых voice ID, положительная консервативная цена тарифа и лимиты в .env.
Счёт провайдера окончательный: неверная локальная цена не гарантирует денежный предел.
Уже отправленный TTS при выходе может закончить кеширование, очередные задания отменяются.
Сбоев аппаратного микшера тестируемый fallback не превращает в остановку игры.

WAV стемы фиксируют громкость на старте клипа; изменения внутри реплики следует брать
из реальной OBS-дорожки. Музыка отдельно в assets/audio/music.wav, в стемах отсутствует.
Video offset основан на acknowledgement OBS; перед монтажом сверить первый удар,
после нарезки пересчитать SRT. Replay пропускает API wait и не воспроизводит voice WAV:
они предназначены для монтажа живой записи. Старые replay могут быть без звуков.
На чистой Windows VM, с настоящими voice IDs и в CapCut импорт ещё не проверялся.
