# Windows — актуальная версия 0.3.2

Сборка `dist/CarromAIShowdown/CarromAIShowdown.exe`. Новый пакет содержит звуки,
авторские комментарии, SRT/WAV-экспорт и опциональный ElevenLabs. Ключи только
в `.env` рядом с EXE; скопируйте `.env.example` вручную, если файла ещё нет.

Актуальные проверки в `RELEASE_REPORT-v0.3.2.md`.

# Windows 11 / v0.3.1

Распакуйте **всю** папку CarromAIShowdown в каталог с правом записи. EXE и `_internal` должны оставаться рядом. Python не требуется для запуска готовой сборки. Подпись издателя и установщик пока отсутствуют.

Двойной щелчок EXE или `Start-Demo.cmd` запускает автоматический демонстрационный матч до двух выигранных игр. Демо использует локальную геометрическую стратегию; названия игроков не означают реальные вызовы моделей.

Для API скопируйте `.env.example` в `.env` рядом с EXE, заполните ключи и идентификаторы доступных вашему аккаунту моделей. Запустите `Start-API.cmd`. Ключи не надо передавать в командной строке. Отсутствующая конфигурация останавливает запуск; переключения на демо нет.

Replay: перетащите файл `*.replay.jsonl.gz` на `Play-Replay.cmd`. SPACE — пауза; ←/→ — пять секунд; ↑/↓ — скорость; HOME/END — начало/конец. Replay не обращается к API.

OBS: запустите OBS Studio с включённым WebSocket v5 и задайте `OBS_PASSWORD` в `.env`. `Record-Demo.cmd` создаёт отдельную сцену захвата окна игры и пишет видео в `recordings`. Окно Carrom должно оставаться видимым: скрытый запуск через `Start-Process -WindowStyle Hidden` не подходит для записи Window Capture. Для API используйте:

```powershell
.\CarromAIShowdown.exe --mode api --official-match --obs-record --obs-setup-scene --obs-output-dir recordings
```

Игра сохраняет прежние сцену, каталог записи и состояние глобальных аудиоисточников, восстанавливает их после записи. Глобальные микрофон и звук компьютера временно выключаются: текущая игра не имеет звуков. При активной чужой записи или трансляции подключение с переключением сцены отвергается. Только собственная запись останавливается при выходе. Сцена Carrom остаётся для следующих запусков. Жёсткое завершение процесса/сбой питания может помешать восстановлению настроек OBS.

CLI работает и у EXE без консольного окна. Для сохранения результата задавайте `--report`:

```powershell
$p = Start-Process .\CarromAIShowdown.exe -ArgumentList '--self-test --log-dir check --report check.json' -PassThru -Wait
$p.ExitCode
.\CarromAIShowdown.exe --replay-info matches\example.replay.jsonl.gz --report replay-info.json
```

`--self-test` проверяет встроенные SDK через локальный HTTP MockTransport, физику и replay. Он не требует ключей, не выходит в сеть и не проверяет доступ к реальным моделям. Ошибки unattended-запуска записываются как тип исключения в `last-error.json`; содержимое SDK-ошибок с потенциальными секретами не сохраняется.

Сборка из исходников: Windows x64, Python 3.14, `Setup.ps1`, затем `BuildWindows.ps1`. Сначала выполняются тесты. PyInstaller собирает каталог `dist/CarromAIShowdown`; `.env`, матчи и исходные архивы не включаются. Проверка готового EXE на компьютере разработчика не заменяет проверку на чистой виртуальной машине Windows.

## Оформление и прицел v0.3.1

`--aim-seconds 1/2/3` — подготовка удара, по умолчанию 2 секунды.
`--board-season all` — случайный выбор среди всех девяти тем.
`--board-theme halloween/new_year/christmas` — фиксированная праздничная тема
(указывайте одно значение). Без этих опций действует календарный случайный выбор.
Тема и время подготовки сохраняются в replay. В сборке PNG находятся в `_internal/assets/boards`.
