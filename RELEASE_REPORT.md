```powershell

.\.venv\Scripts\python.exe -m pytest -q --junitxml=validation-tests.xml
.\.venv\Scripts\python.exe game.py --mode demo --headless --official-match --max-turns 240 --max-boards 30 --log-dir matches --report official-match.json

# Из Windows bundle
.\CarromAIShowdown.exe --self-test --log-dir check --report check.json
.\CarromAIShowdown.exe --replay-info demo-board-v0.3.replay.jsonl.gz --report replay-info.json
.\CarromAIShowdown.exe --replay demo-board-v0.3.replay.jsonl.gz
```

Проверены Python **3.14.0**, pygame-ce 2.5.8, Pymunk 7.3.0, OpenAI 3.28.0,
Anthropic 1.13.0, websocket-client 1.9.2, PyInstaller 6.22.3. Полное окружение —
`requirements-tested-win314.txt`. Жеребьёвка воспроизводима через `--toss-seed`;
`--round-stage` управляет условием смены сторон.

## Практические границы

Это двумерная singles-игра с виртуальным судьёй. Применимость человеческих,
вертикальных и организационных процедур описана в RULES_COVERAGE.md;
сертификации федерации нет. Лимит ходов, шесть последовательных ошибок API и
таймаут физики означают техническое прекращение, а не спортивную ничью/победу.

Матч выше проведён **локальными demo-стратегиями**, не реальными моделями.
Оплачиваемые API-запросы, доступ к моделям, 429/5xx и стоимость не проверялись.
Для этого нужны действительные ключи и согласованный бюджет.

Replay сохраняется по бордам, не возобновляет API-запросы, пропускает ожидание
API и межбордовые паузы. OBS-ролик — короткая проверка EXE, не видео всего матча.
FPS сохранён из настроек OBS; 1080p60 можно настроить отдельно. Сцена Carrom
остаётся для повторного использования. Игра пока не имеет звуков; глобальные
микрофон и звук компьютера временно выключаются на время записи.

EXE проверен на этом компьютере Windows 11. Чистая VM без установленного Python
не проверялась. EXE не подписан, установщика нет; распакуйте весь каталог в место
с правом записи. Жёсткое завершение процесса может помешать восстановлению OBS.
