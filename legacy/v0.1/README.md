# Carrom AI Showdown — версия 0.1

Первый **исполняемый прототип** игры «ChatGPT vs Claude» для Windows 11.
Это пока не полная реализация правил Carrom, а игровое ядро для дальнейшей разработки.

## Запуск

1. Установите Python 3.11–3.13 и откройте папку проекта в VS Code.
2. В терминале PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python game.py
```

3. Нажмите **ПРОБЕЛ** — один ход. Дождитесь остановки фишек и нажмите снова. **R** — новая партия, **ESC** — выход.
4. Режим `MODE=demo` работает без интернета и ключей: обе стороны используют простую локальную стратегию, а **не** настоящие модели ChatGPT и Claude. При демонстрации не называйте такие ходы решениями реальных ИИ.

## Реальный матч OpenAI API против Anthropic API

Откройте `.env` и поставьте `MODE=api`. Вставьте ключи `OPENAI_API_KEY` и `ANTHROPIC_API_KEY` (никогда не публикуйте этот файл). Задайте в `OPENAI_MODEL` и `ANTHROPIC_MODEL` **точные идентификаторы моделей, доступных вашему аккаунту**, согласно документации и тарифу соответствующих API.

Примечание: заявленное название «Claude Sonnet 5.5» не подтверждено разработчиком этого прототипа как API-модель; не путайте маркетинговое имя и фактический модельный ID. Значения в `.env.example` — заменяемые примеры, а не обещание доступности.

Каждый ход передаёт модели координаты фишек и счёт. Модель возвращает JSON `{ "x": 380, "angle": 270, "power": 0.7, "comment": "..." }`. Python валидирует диапазоны. Ошибка сети или API не выдаётся за результат матча и показывается в игровом интерфейсе. Использование API оплачивается отдельно от подписки ChatGPT.

## Что уже реализовано

- Доска 760×760, четыре лузы, девять белых, девять чёрных и красная королева.
- Pygame-отрисовка и Pymunk-физика движения/столкновений.
- Чередование ходов, упрощённый подсчёт очков, базовый штраф за попадание битка в лузу.
- Передача состояния и проверка ответов двух LLM API.
- Загрузка ключей из `.env`, локальный демонстрационный режим.
- Ручное управление началом каждого хода, подходящее для записи OBS.

## План полноценной версии

**Этап 1. Физика и удобство (текущий MVP).** Стабилизировать контакты возле луз, скорость, friction, placement, добавить настройку размеров по общепринятым правилам, автоследование ходов и индикатор ожидания сети.

**Этап 2. Полные правила Carrom.** Явно выбрать официальный набор правил (турнирные/домашние), добавить начальную расстановку, корректные лузы, право на удар, фолы, возврат фишек, королеву и её покрытие, условия завершения партии и серии, тесты на каждое правило.

**Этап 3. Честный AI-матч.** Обе модели получают идентичный JSON состояния и одинаковые доступные действия. Исключить доступ к случайным «подсказкам» противника. Записывать сырые ответы API, выбранные параметры, стоимость токенов, версии моделей, время ответа, seed и результаты симуляции. Разделить решения моделей и придуманные реплики комментаторов.

**Этап 4. Сила игры.** Добавить предварительный физический расчёт возможных траекторий, допустимые варианты удара и оценку удара; провести 20–100 тестовых партий. Это сделает игру осмысленнее случайного выбора угла.

**Этап 5. YouTube Production.** OBS, динамический HUD, индикатор силы и направления, повторы, музыка без проблем с правами, SFX, титры и отдельная дорожка с комментариями, кнопка записи событий JSON/CSV.

**Этап 6. Релиз.** Настройки, сохранение и повторы матчей, статистика побед, турнир до 3/5 побед, автозапуск, обработка сетевых сбоев, Windows-сборка через PyInstaller, инструкция по ключам и тестированию.

## Известные ограничения версии 0.1

- Правила и очки намеренно упрощены: королева сразу даёт 2 очка; нет покрытия королевы и возврата фишек.
- Биты и столкновения физически приближённые, без калибровки под реальную доску.
- Ответы API могут быть тактически слабыми: языковая модель не является геометрическим оптимизатором.
- Интернет, доступ к нужным моделям и оплачиваемые API-ключи необходимы только в режиме `api`.
- Прототип не запускает последовательные ходы автоматически и не записывает видео: пока это делает человек с OBS.
